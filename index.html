    • Sobre mí

    Actualmente estoy cursando el segundo año del Bachelor’s Degree in Data Science, en Universitat Carlemany .

    • Formación intensiva de un año como interno junto a dos Data Scientists, desarrollando un perfil junior en Machine Learning.
    • Habilidades en modelos supervisados y no supervisados, NLP y redes neuronales.
    • Análisis avanzado de datos: PCA, detección de outliers, estudio de homogeneidad y heterocedasticidad.
    • Implementación de pipelines completos: Label Encoding, One-Hot Encoding, escalado de variables y manejo de valores nulos.
    • Optimización de modelos con GridSearch y técnicas de balanceo de datasets (undersampling/oversampling).

    Pasión por la Ingeniería y la Ciencia de Datos: Me motiva trabajar en entornos complejos, diseñando pipelines robustos y creando modelos que resuelvan problemas reales. Estoy en constante aprendizaje y disfruto optimizando sistemas para mejorar el rendimiento y la accesibilidad de datos, contribuyendo a decisiones fundamentadas y escalables.

    Proyectos

    Students Performance

    Este proyecto se centra en la predicción de calificaciones de exámenes utilizando el Huber Regressor, un modelo de regresión robusto capaz de manejar outliers. Se analizaron los datos con visualizaciones de variables continuas y categóricas para comprender mejor el dataset. Se construyó un pipeline que gestiona valores nulos y codificación de variables categóricas, rellenando los faltantes con la moda. Además, se empleó GridSearch para ajustar los hiperparámetros y optimizar el rendimiento del modelo.

    Arquitecturas Big Data

    Flask + Celery + Redis + Supabase Este proyecto pone en práctica los fundamentos básicos de una arquitectura Big Data y sistemas escalables, enfocándose en la gestión eficiente de grandes volúmenes de información sin saturar la base de datos. En lugar de acceder directamente a la base de datos ante múltiples peticiones simultáneas, se aplica una arquitectura asíncrona y desacoplada para reducir latencia y evitar cuellos de botella. La solución se basa en Flask como servidor web, Redis como sistema de caché y cola FIFO, Celery para el procesamiento asíncrono de tareas y Supabase (PostgreSQL) como base de datos para la persistencia final de los datos.

    YouTube Inspector 1.0

    YT Sentiment Inspector v1.0 analiza comentarios de hasta cinco vídeos de YouTube para evaluar el sentimiento del público. Incluye WordClouds, gráficos de frecuencia y detección de sarcasmo y lenguaje ofensivo con modelo previamente entrenados con XGBClassifier, utilizando NLTK (SIA) para un análisis fiable.

    Agricultural Yield Prediction


    Dataset: 28,242 records with agricultural production and environmental factors across multiple countries.
    Features: rainfall, temperature, pesticide usage, crop type, geographic area.
    Goal: Predict crop yield (hg/ha) using Machine Learning.
    Performance: MSE: 147,928,888.34, RMSE: 12,162.60, MAE: 3,653.40, R²: 0.98.
    Insights: Understand how climate and environmental conditions affect agricultural productivity.

    Loan Predictor

    Predicción de Riesgo Hipotecario. Proyecto de Machine Learning orientado a predecir si un cliente pagará su deuda bancaria. Tras un análisis EDA y el tratamiento del fuerte desbalanceo de clases, se entrenaron y evaluaron múltiples modelos. El modelo final seleccionado fue AdaBoost, integrado en un pipeline de preprocesamiento y optimización con GridSearch, alcanzando un Accuracy del 87%, Recall del 69% y Precision del 100%.

    Geotab Data Visualization

    Proyecto práctico utilizando la API de Geotab para la visualización de datos en tiempo real. En este proyecto analizo kilómetros recorridos fuera de horario, dentro de la jornada laboral, errores de los vehículos y su ubicación. También genero gráficos interactivos y mapas de puntos calientes que muestran las zonas donde los vehículos suelen transitar con mayor frecuencia, aplicando técnicas de análisis de telemetría para una mejor eficiencia operativa.
